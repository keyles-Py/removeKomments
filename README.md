# removeKomments
A GUI program that removes both single-line and multi-line comments from your code. It works with Python, Java, HTML, CSS, and JavaScript.

## Features
- **Single & Multi-File Upload**: Upload individual files, attach multiple files at once, or drag and drop folders into the browser.
- **Direct Directory Scanning**: Specify a local folder path to scan and clean all supported code files recursively (automatically ignoring build/vcs folders like `.git`, `venv`, `node_modules`).
- **Zip Archive Export**: Download all cleaned files in a neatly structured ZIP archive.
- **Local Disk Output**: Optionally save cleaned directory output directly to a target folder.
- **Supported Languages**: Python (`.py`), Java (`.java`), HTML (`.html`), CSS (`.css`), and JavaScript (`.js`).
